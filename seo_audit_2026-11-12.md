## Details

### Technical SEO — verified clean
- **Titles:** all 118 pages have unique titles (0 duplicates). Suffix `· Adhyayan` consistent.
- **Canonicals:** present on every page, self-referential, trailing-slash consistent, correctly derived from `Astro.site` (resolution order SITE_URL → VERCEL_PROJECT_PRODUCTION_URL → placeholder; preview deploys keep production canonicals — correct design). Only oddity: the 404 (#13).
- **robots.txt** (`src/pages/robots.txt.ts`): generated from site config so the Sitemap URL can never diverge from `site`; `Allow: /`. The deliberate choice to allow crawling while noindexing previews (`Base.astro:41-44` comment) is correct — a robots Disallow would hide the noindex.
- **Sitemap:** sitemap-index.xml + sitemap-0.xml, 118 URLs, valid XML. Problems are inclusion only (#1, #8) — no filter is configured.
- **noindex:** only the global `indexable` gate (#2); no stray per-page noindex.
- **hreflang:** n/a (single language) — correctly absent. `lang="en"` set, viewport meta correct, theme-color / manifest / icons / apple-touch-icon present.
- **Images:** 0 `<img>` without alt across the whole build (most pages use no raster images).
- **og:image:** exists (`public/og-image.png`, 1200x630 declared), absolute URL. One shared image site-wide — per-guide og images are nice-to-have only.
- **URLs:** clean, descriptive, hierarchical (`/foundation/<paper>/<chapter>/`).
- **Internal linking:** chapter ↔ hub ↔ home reachable within 3 clicks; visible breadcrumb nav on chapters (`aria-label="Breadcrumb"`); footer links the 5 money guides. Orphans in #9.

### Content/intent mapping
Covered (titles mostly match query phrasing):
- "CA Foundation weightage" → `/guides/ca-foundation-weightage/` (title 34 chars — could add year + "chapter-wise marks" for CTR)
- "CA Foundation pass percentage" → `/guides/ca-foundation-pass-percentage/` (desc 134 chars — one of the few at ideal length)
- "CA Foundation exam pattern" → `/guides/ca-foundation-exam-pattern/`
- "CA Foundation RTP / MTP" → `/guides/ca-foundation-rtp-mtp/`
- "free CA Foundation resources / study material" → `/guides/ca-foundation-free-resources/`
- Per-chapter topics → 46 chapter pages (need title fix #4 to actually match "<topic> CA Foundation" phrasing)

Not covered, ranked by likely volume:
1. **"CA Foundation syllabus [2026/2027]"** — nothing targets it; biggest single gap.
2. **"CA Foundation Jan 2027" / "exam date Jan 2027"** — attempt landings are repeatable templates (dates, form window, admit card, countdown, links to plan + mocks) and the natural internal-link target from every chapter footer.
3. **"CA Foundation registration / eligibility / after 12th"** — top-of-funnel, pairs with the "how to become a CA" head.
4. **"CA Foundation mock test"** — page exists but the title says neither CA nor free (#12).
5. **"CA Foundation MCQs <chapter>"** — the quiz lives behind query params (`/practice/quiz/?level=...`), invisible to crawlers. Static per-paper MCQ landing pages are a later structural play.

Title phrasing rule of thumb for this audience: "<topic> CA Foundation" for chapters, "CA Foundation <thing> <year/attempt>" for guides; refresh year-bearing titles each attempt.
